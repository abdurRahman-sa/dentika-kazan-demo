# Design Guidelines — Dentika (Казань), версия 1 (концепт «Досье/Ledger»)

Проект: демо-сайт для Dentika, стоматология, Казань
Версия макета: v1 (одобрена как основа для сборки)
Референс: `design/concept-v1-ledger.html` (упрощённый HTML-мокап, лежит рядом, в `dental-kazan/dentika/design/`)
Тип страницы: **одностраничный лендинг** (внутренняя навигация якорями, без роутинга между URL)

---

## 1. Технический стек

- Astro + Tailwind CSS (build step, **не** CDN-подключение)
- Шрифты — через `@font-face`/Google Fonts import в `global.css`, не инлайновые `<link>` на каждой странице
- Форма записи — визуальная имитация (без реальной отправки данных на этом этапе, см. `../../_templates/tech-stack.md` и `../../_templates/legal-compliance-ru.md`)

---

## 2. Цветовая палитра

Добавить в `tailwind.config.mjs` → `theme.extend.colors`:

```js
colors: {
  ink:   '#171F26', // текст, каркас, header
  bg:    '#EDEFEA', // фон страницы
  teal:  '#2F6E68', // акцент №1 — цены, CTA записи, активные состояния
  gold:  '#B98A3B', // акцент №2 — только блок дипломов/сертификатов
  slate: '#6B7A82', // вторичный текст, hairline-линии, разделители
  brick: '#8C3A3A', // плашка юридического дисклеймера
}
```

Правила использования:
- `teal` — **только** там, где показываются данные, которых нет у конкурентов (цены, реальные слоты записи, CTA). Не использовать как общий брендовый цвет по всему сайту.
- `gold` — **только** в блоке врачей/сертификатов. Не использовать нигде больше.
- `brick` — **только** для юридической плашки о противопоказаниях (ст. 24 ФЗ «О рекламе»).
- Фон `bg` — на всю страницу, без белых "карточек-подложек" с одинаковой серой тенью (см. раздел 6, "чего избегать").

---

## 3. Типографика

```css
@import url('https://fonts.googleapis.com/css2?family=Bitter:wght@500;700&family=IBM+Plex+Mono:wght@400;600&family=Public+Sans:wght@400;500&display=swap');
```

Tailwind `fontFamily`:
```js
fontFamily: {
  slab: ['Bitter', 'Georgia', 'serif'],
  mono: ['"IBM Plex Mono"', 'monospace'],
  sans: ['"Public Sans"', 'system-ui', 'sans-serif'],
}
```

| Роль | Класс | Где применять |
|---|---|---|
| Заголовки H1/H2 | `font-slab` | Заголовок героя, заголовки секций |
| Цифры/данные | `font-mono` + `tabular-nums` | Цены в услугах, номер лицензии, слоты записи, рейтинг |
| Основной текст | `font-sans` (по умолчанию) | Описания, форма, футер |

## 4. Layout — структура секций

Порядок блоков (Слой 1 обязателен, Слой 2 — дифференциаторы из `../research-result.md`):

1. **Rail-навигация** (левая колонка на desktop, горизонтальный скролл-бар на mobile) — якоря на секции ниже, метки — обычным регистром, не CAPS. Индикатор активного пункта — маленький прямоугольный "зубцовый" маркер (`teal` для активного, `slate` для остальных), не точки/цифры.
2. **Hero** — асимметрично, 60/40, НЕ по центру. Слева заголовок+подзаголовок+CTA («Записаться на приём», без стрелки `→`). Справа — белая плашка с номером лицензии и рейтингом (2ГИС), `font-mono`.
3. **Услуги** — построчный ledger (не карточки-плитки): название слева, цена справа `font-mono`, разделитель — пунктирная hairline-линия, НЕ таблица с рамками. *(Слой 2: цены открыты — дифференциатор, у 6 из 8 лидеров рынка цены закрыты)*
4. **Врачи** — карточка на белом фоне, hairline-рамка (не тень), + отдельный "diploma chip" (наклон -2°, окантовка `gold`, фон `#fbf3e3`, текст «скан диплома ✓»). *(Слой 2: диплом рядом с карточкой врача — этого нет ни у одного из топ-8)*
5. **До/после** — горизонтальная лента 3 плейсхолдеров под локальные фото (зубы/полость рта, без лиц). *(Слой 2)*
6. **Форма записи** — визуальный календарь: чипы дат+времени, занятые слоты — приглушённые и зачёркнутые. НЕ форма «оставьте заявку». *(Слой 2 — ключевой дифференциатор, есть только у 1 из 8 лидеров)*
7. **Контакты** — адрес, часы работы, номер лицензии в футере секции.
8. **Юридическая плашка** — фиксированная полоса `bg-brick`, белый текст, 11–12px: предупреждение о противопоказаниях/необходимости консультации (обязательно по ст. 24 ФЗ «О рекламе», см. `../../_templates/legal-compliance-ru.md`).

### Breakpoints
- Desktop (`lg:` ≥1024px): rail слева фиксирован, ширина ~130px
- Mobile (`<640px`): rail превращается в горизontальный скролл под header, `flex-direction: column` для hero и карточек врачей

### Отступы/радиусы
- Border-radius: 2px везде (не 8-16px скруглённые карточки)
- Тени не используются — только `border: 1px solid` в оттенке `slate`-lighten (`#d8dad3`)
- Карточки на белом (`#fff`), фон секций — `bg`

---

## 5. Компоненты — точные спеки из мокапа

- **Ledger row**: `flex justify-between`, `border-bottom: 1px dashed`, цена — `text-teal font-mono`
- **Doc card**: белый фон, `border: 1px solid #d8dad3`, `padding: 16px`, без `box-shadow`
- **Diploma chip**: `display:inline-block; transform: rotate(-2deg); background:#fbf3e3; border:1px solid gold; font-size:10px; padding:4px 9px`
- **Slot (запись)**: `border:1px solid teal; color:teal`, занятый — `border-color:#d8dad3; color:#b9bdb4; text-decoration:line-through`
- **CTA-кнопка**: заливка `teal`, белый текст, `border-radius:2px`, **без иконки-стрелки**

---

## 6. Обязательно избегать (клише, которые клиент уже отклонял)

- Кремовый фон + терракотовый акцент (~#D97757)
- Тёмный фон с одним ярким неоновым акцентом
- Карточки с одинаковым скруглением + одна и та же серая тень у всех
- ВСЕ ЗАГЛАВНЫЕ ярлыки, разделители через «·»
- Стрелка `→` после текста кнопок/ссылок
- Числовые маркеры 01/02/03 там, где это не реальная последовательность
- Дефолтные шрифты (Inter/Poppins/Manrope) — использовать только шрифты из раздела 3

---

## 7. Контентные и юридические ограничения

- **Фото**: без лиц людей/животных. Допустимы — локальные фото частей тела в контексте услуги (зубы/полость рта), фото кабинета/оборудования, сканы дипломов/сертификатов, иконки вместо портретов.
- **Тексты услуг/CTA**: без превосходных степеней, без сравнений с конкурентами, без гарантий результата лечения (ст. 24 ФЗ «О рекламе»)
- **Обязательно на странице**: чекбокс согласия на обработку ПДн в форме записи (даже визуальной), ссылка на политику конфиденциальности, номер лицензии в футере — сверить с `../../_templates/legal-compliance-ru.md`

---

## 8. Что нужно от вас перед стартом верстки (плейсхолдеры v1)

- Реальный номер лицензии (или временно `№ ЛО-16-01-XXXXXX`, если под демо без реального клиента)
- 2–3 реальных или стоковых фото для блока «До/После» (без лиц)
- 2 карточки врачей (имя/специализация/стаж — можно вымышленные для демо)
- Финальный список услуг с ценами для ledger-блока (можно ориентировочные — «от»)
